# Breez SDK - Greenlight is deprecated

The Breez SDK - Greenlight (`breez-sdk-greenlight`) is **deprecated and no longer maintained**. Its documentation has been retired. It should not be used for new integrations, and existing integrations should move off it.

## Build with the Breez SDK - Spark

To add instant, non-custodial bitcoin and stablecoins to your app or service, build with the Breez SDK - Spark.

**[Breez SDK - Spark documentation](https://sdk-doc-spark.breez.technology/)**
